A skill for agents

Model it exactly.
Take it apart.
Film it.

Give it a real object. It looks the numbers up, writes a spec where every number says where it came from, and renders a film, a viewer and a 3D model. If the numbers do not add up, it does not render. The Enigma model has to reproduce the published test: AAAAA becomes BDZGO.

Type on the EnigmaWatch the filmsInstall
SourcedEvery number is SPEC, MEASURED, DERIVED or ESTIMATED, with its source or its reason.
GatedA spec whose gears, ratios or test vectors do not check out is not rendered.
Three outputsA film with designed sound, an interactive viewer, and an STL / GLB of the model.

The check is on the card.

Each one carries what its model had to reproduce, and says plainly what it could not source.

Rubik's Cube

20-move superflip, reproduced

26 pieces that really turn, no tables. The model has to flip all 12 edges in the published 20 moves, come back after 1,260 repeats of the longest sequence, and count 43,252,003,274,489,856,000 positions.

Honda K20A

1,998 cc and 1-3-4-2, checked; rod is a guess

A real crank-slider: 16 valves, cams placed from the valve windows. Displacement is computed from bore and stroke, and the published firing order must be possible with the crank. Honda does not publish the rod, so it is dashed.

Open the viewer

It looks things up before it draws anything.

The skill's job is evidence. The engine and the sound are built to serve it.

Research

Spec sheets, teardowns, official photos, published test vectors. It opens the pages and the pictures.

Spec

Parts with real dimensions, the evidence behind each number, and how it moves.

Gate

Sources, cross-checks, centre distances, published ratios and test vectors. Wrong specs stop here.

Render

Camera, sound and panels are directed from the spec: a film, a viewer and a 3D model.

// a part, with the evidence it stands on { id: 'ring', kind: 'ring', p: { m: 0.8, z: 60, ro: 27.4, width: 8 }, conf: 'derived', claims: ['teeth', 'formula'] } // and the claim behind it { id: 'teeth', conf: 'derived', src: ['cyclechat', 'princeton'], cross: 'zr = zs + 2 zp holds (60 = 20 + 40)' }
# the gate: a spec that does not add up is not rendered $ node scripts/check-spec.mjs examples/hub/spec.js mode Gear 3: 1.3333, published 1.3333 ok PASSES # change one planet to 21 teeth, the claim to 150 % ERROR centre distance ring-p1: 16.400 mm, needs 15.600 mm ERROR mode Gear 3: the model gives 1.3333, published 1.5 DOES NOT PASS
spec

Published by the maker or a datasheet.

measured

Measured on an official photo, scale from a published size, error stated.

derived

A formula plus a cross-check against another published number.

estimated

Nobody publishes it. Drawn dashed, and said out loud.

Use it as a Claude Code skill.

Clone it into your skills folder and ask for an exploded view of something real. Needs Node 22+, Edge or Chrome, and ffmpeg.

# macOS / Linux git clone https://github.com/DiegoLopez0208/mechanism \ ~/.claude/skills/mechanism # Windows (PowerShell) git clone https://github.com/DiegoLopez0208/mechanism ` $env:USERPROFILE\.claude\skills\mechanism
# then, in Claude Code "Use mechanism to model a mechanical keyboard switch exactly, with its sources" # or drive the toolkit yourself node scripts/new.mjs my-object --title "My object" node scripts/check-spec.mjs examples/my-object/spec.js node scripts/render.mjs examples/my-object/index.html
